
# 🧮 Basic Calculator

A simple and interactive **Basic Calculator Web Application** built using HTML, CSS, and JavaScript.

This project performs basic mathematical operations with a clean, user-friendly interface and interactive buttons.

## 🚀 Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Clear (AC) button
- Delete (DEL) button
- Responsive and attractive user interface
- Interactive button hover effects
- Real-time calculation

## 🛠️ Technologies Used

- **HTML5** – Structure of the calculator.
- **CSS3** – Styling and user interface design.
- **JavaScript** – Calculator functionality and logic.

## 📂 Project Structure

```text
Calculator/
│
├── index.html
├── style.css
└── script.js
```

## 💻 How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start using the calculator!
